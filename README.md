# Ночная смена — атлас «Сон и мозг: что происходит ночью»

Одностраничный интерактивный 3D-атлас в духе советского научпопа 1960-х.
Three.js подключается через import map с jsDelivr, сборки нет: `index.html`, `style.css`, `main.js`.

Локально: `python3 -m http.server` в корне репозитория и откройте http://localhost:8000.

Атлас научно-популярный и не является медицинской консультацией.
